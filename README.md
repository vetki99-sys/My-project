# Smart Calculator - آلة حاسبة ذكية

تطبيق آلة حاسبة احترافي لنظام Android يدعم جميع أنواع الحسابات.

## المميزات

- **8 أنواع من الآلات الحاسبة**: أساسية، علمية، بيانية، مالية، هندسية، برمجية، إحصائية، زمنية
- **دعم أكثر من 50 لغة عالمية** مع دعم RTL للعربية والعبرية
- **تصميم Material 3** حديث ومتجاوب
- **دقة حسابية عالية** باستخدام BigDecimal
- **محرك رسم بياني** متكامل
- **تخزين محلي** للسجل والمفضلات
- **ودجت للشاشة الرئيسية**
- **مجاني تماماً** مع إعلانات غير مزعجة

## المتطلبات

- Android Studio Hedgehog (2023.1.1) أو أحدث
- JDK 17
- Android SDK 34
- Gradle 8.4

## البناء

1. استنسخ المشروع:
```bash
git clone https://github.com/yourusername/SmartCalculator.git
```

2. افتح المشروع في Android Studio

3. انتظر تحميل التبعيات

4. اضغط على `Build > Make Project`

## هيكل المشروع

```
SmartCalculator/

│   │   └── res/               # الموارد

├── build.gradle
└── settings.gradle
```
